1. 현재 보유 역량

- Python 숙련도: 중급 (검색하며 개발 가능)
- AI/ML 경험: bootcamp시 LLM기반 개발, sllm을 활용한 개인학습용 개발 경험
- LLM 활용 경험: chatGPT, gemini를 사용 중이며 sllm(ollama+gemma4 + LangChain)일부 사용 경험
- RAG/Agent 구현 경험: 유, bootcamp진행시 langchain + MCP(RAG) 시스템을 구축 경험이 있고, 최근 AdvanceRAG 와 Modular RAG에 관심있음.
- 프로젝트 경험: 없음

2. 학습 필요 영역

- 프레임워크 기초 & 심화: LangChain / LangGraph 기초 확립
- 데이터베이스 활용: 
  - Vector DB: FAISS, Qdrant 두개의 Vector DB를 속도, 운영 편의성, 정확도를 비교분석 후 구현할 프로젝트의 적합도를 판단
- 핵심 AI 기술: 
  - RAG (Retrieval-Augmented Generation) 고도화 구현
  - Multi-Agent 시스템 아키텍처 설계
  - 프롬프트 엔지니어링 (Prompt Engineering) 최적화

3. 기술 스택 선호도

- RAG 오케스트레이션 (Orchestration)
  - LangChain 및 LangGraph 기반의 고도화된 RAG 워크플로우 제어

- 검색 전처리: 질문 재작성 (Query Rewriting)
  - 사용자의 모호하거나 복잡한 자연어 질문을 LLM을 통해 정제 및 확장
  - 다양한 표현 방식(표현 다각화)을 적용해 Vector DB 검색의 정확도(Recall) 극대화

- 검색 후처리: 리랭킹 (Reranking)
  - 1차 유사도 검색 결과 중 조달 규정 및 법령 문서와의 실제 시맨틱(의미론적) 연관성을 재평가하여 최상위 콘텍스트 선별

4. 프로젝트 관심 도메인

1순위 도메인: 공공 (Public Sector)
2순위 도메인: 금융 (Finance)
관심사유 : 현재 공공기관 프로젝트 수행 경험이 풍부하여 업무 프로세스와 규정(절차) 이해도가 매우 높음. 도메인 지식(Domain Knowledge)의 강점을 살려 실제 현업의 페인 포인트를 해결하는 특화 AI 솔루션 구축이 가능함.

5. 8주 목표 설정

기술목표:
- 협업형 Multi-Agent RAG 아키텍처 구현: 단일 RAG의 한계를 넘어, 복잡한 태스크를 분할·해결하는 멀티 에이전트 시스템 설계 및 제어 역량 내재화.
- AI-Driven 고속 개발 방법론(Vibe Coding) 체득: Claude를 단순한 코드 생성 도구가 아닌 '페어 프로그래머'로 적극 활용하여, 개발 생산성을 극대화하고 아키텍처 설계에 집중하는 효율적인 개발 프로세스 정립.

비즈니스 목표:
- 공공 조달 특화형 Vertical AI Agent ('조달업무 어시스턴트') 구축
  - 공고문, 입찰서, 제안요청서(RFP) 등 조달청 및 대관 업무에 사용되는 복잡한 정형·비정형 문서를 효율적으로 파싱(Parsing) 및 학습.
  - 분석된 핵심 데이터를 기반으로 조달 프로세스 자동화 및 전자시스템 반영을 지원하는 도메인 특화 에이전트 완성.

성장 목표:
- Lv.3 Middle급 AI 개발자로서의 기술적 실무 역량 검증
  - 아키텍처 설계부터 Advanced RAG 파이프라인 구현까지 전 과정을 주도하여 미들급 개발자로서의 포트폴리오 확보.
- 공공 도메인 AI 컨설팅 및 소통 역량 강화
  - 공공기관 고객의 복잡한 요구사항과 규제 가이드라인을 정확히 해석하고, 이에 맞는 AI 솔루션 레이아웃을 제안·설득할 수 있는 비즈니스 전문성 개발.
